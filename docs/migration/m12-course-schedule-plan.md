# M12：课程表体验整合（日期跳转 / 一周视图 / 导出）目标文档

> 状态：规划中（2026-08-09 立项）。范围与验收以本文档为准；实施计划另附。
> 上游需求来源：用户 2026-08-09 提出课程表日期跳转、一周整合视图，并补充课程表导出功能；三者同属课程表体验，合并为 M12 的 a/b/c 三个子项。

## 1. 背景与现状

KMP 课表（M5-2）已支持「本学期课表 / 选课课表」切换与「全部 + 1–26 周」周选择，但仍有三个体验缺口：

| 缺口 | 现状 | 影响 |
|---|---|---|
| 只能按「第几周」选，不能按具体日期 | 课表数据本身不带日期，周→日期映射未接入 | 计划出门时无法快速看「9 月 15 日有没有课」 |
| 紧凑端只有单日视图 | 手机按「周一~周日」切换，看一周要多次点按 | 无法一眼扫视整周安排 |
| 无导出 | 考试（M12 原案）有导出日历规划，课表没有 | 无法把课表导入系统日历做长期规划 |

M11 教室占用查询已验证 bksy `SemesterTranPage` 的 `hidJson` 周→日期映射，课表可直接复用。

## 2. 目标

把课程表从「按周浏览」升级为「按日期可查、整周可看、可导出」：

- **M12a 日期跳转**：提供一个日历/日期选择入口，点任意日期自动定位到对应教学周与星期几，显示当天课程。
- **M12b 一周整合视图**：在紧凑端提供可横滑或缩略的一周视图；宽屏保持现有七日网格，并强化日期标注。
- **M12c 课程表导出**：把课程表导出为系统日历可导入的格式（首版 ICS），支持本学期课表与选课课表。

## 3. 子项范围

### M12a：课程表日期跳转

- 复用 M11 的 bksy `hidJson` 解析，建立「日期 ↔ 教学周 + 星期几」映射。
- 课表页新增「按日期查看」入口（日历弹层或日期选择器）。
- 选择日期后自动切换 `selectedWeek` 与 `selectedDay`，并显示该日期对应的课程。
- 非教学周日期（假期、考试周）给出明确空态提示。

### M12b：手机一周整合视图

- 紧凑端新增「周视图」模式：七日列压缩展示，支持横滑切周、点按看当天详情。
- 与现有「单日视图」并存，用户可切换；默认保持单日视图，避免破坏既有习惯。
- 宽屏/macOS 现有七日网格增强：列头显示对应日期，不只是「周一~周日」。

### M12c：课程表导出日历

- 共享层生成课程 ICS：每门课按周重复（`RRULE`），或展开为逐周事件；含课程名、时间、地点、教师。
- 导出范围：当前筛选的课表类型（本学期/选课）+ 当前学期全部周，或用户自选周范围。
- 三端落点：Android 分享/保存、iOS 分享/文件、macOS `NSSavePanel`；取消不显示红色错误。
- 与 M12a 的日期映射共用同一套周→日期数据。

## 4. 平台差异

| 平台 | M12a 日期跳转 | M12b 一周视图 | M12c 导出 |
|---|---|---|---|
| Android/iOS 紧凑 | 底部日历弹层 | 七日缩略横滑 + 点按详情 | 系统分享/保存面板 |
| macOS 宽屏 | 工具栏日期选择器或侧栏迷你日历 | 现有网格列头加日期 | `NSSavePanel` 保存 `.ics` |
| 共享层 | 日期↔周映射为纯 Kotlin 状态逻辑 | 周视图状态与布局自适应 | ICS 生成器复用考试导出同款 |

## 5. Apple 设计要求

- **响应**：点日期/切周立即反馈，不等网络；日期选择器打开即显示，不加载。
- **可打断**：日历弹层、周视图横滑均可中途抓取反向；导出进度可取消。
- **空间一致**：日期弹层从触发按钮展开；周视图进入/退出沿同一路径。
- **克制弹性**：日期切换、周滑动用临界阻尼；导出成功用轻量反馈。
- **反馈完整**：日期无课、导出中、导出成功/失败/取消各有明确状态。
- **排版可伸缩**：日期、课程名、地点在窄屏不截断关键信息；支持动态字体。

- [ ] 浅色/深色、窄/宽窗口、文字放大通过视觉验收。

- [ ] 导出取消不残留半成品；批量导出进度可见、可取消。

## 7. 待调研（实施前必须闭环）

- [ ] 课程时间文本（`courseTimeAndPlace` 或类似字段）的全部真实格式，能否可靠解析为起止时间。

## 8. 依赖与风险

- **依赖**：M5-2 课表数据与缓存；M11 bksy 日期映射；M12 原案考试导出的 ICS 生成器（若先做）。
- **风险**：课程时间格式不规则 → 解析器必须宽容，保留原文本兜底；紧凑端七日视图可能过密 → 需真实设备目视验收，必要时回退为「周概览条 + 单日详情」。
